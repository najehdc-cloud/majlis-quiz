# Majlis Quiz — phone controller

This is the page players open (by QR code or shared link) to join a Majlis Quiz game running on an Android TV.

- `index.html` — the phone controller (join, answer, results)
- `cloud.js` — tiny Firebase client (anonymous sign-in + Realtime Database)
- `config.js` — Firebase project settings

Link format: `https://najehdc-cloud.github.io/majlis-quiz/?r=ROOMCODE`
